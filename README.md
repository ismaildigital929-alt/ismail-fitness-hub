# Build a Premium Modern Gym Website for "Ismail Digital"

Create a modern, premium, fully responsive gym and fitness website for a brand called **Ismail Digital**.

## Brand Information

* **Brand Name:** Ismail Digital
* **Email:** [ismaildigital929@gmail.com](mailto:ismaildigital929@gmail.com)
* **Business Type:** Gym & Fitness Center
* **Brand Positioning:** Premium, energetic, modern, motivational and professional

## Overall Design

Create a high-end fitness website that looks like a professional commercial gym website.

The design should feel:

* Powerful
* Athletic
* Premium
* Modern
* Energetic
* Clean
* Motivational

Use a **dark luxury fitness aesthetic** with a strong contrast between dark backgrounds and an energetic accent color.

### Color Palette

Use:

* Primary background: #080808
* Secondary background: #111111
* Cards: #181818
* Primary text: #FFFFFF
* Secondary text: #A0A0A0
* Accent: #E5FF00 (electric lime)
* Borders: subtle dark gray

Use the accent color strategically for buttons, headings, highlights, icons and important calls-to-action.

## Typography

Use a bold modern sans-serif font such as **Inter, Manrope, or Poppins**.

Headings should be:

* Large
* Bold
* Strong
* Athletic

Body text should be clean and easy to read.

# IMAGE DIRECTION

Use premium, realistic fitness photography.

Image style:

* Professional gym photography
* Muscular athletes
* Modern gym interiors
* Strength training
* Dumbbells and barbells
* Personal training
* HIIT workouts
* Fitness transformations

Avoid:

* Cartoon images
* Cheap-looking stock photography
* Overly saturated images
* Low-resolution images
* Images with visible watermarks

Images should have a dark, cinematic, premium fitness aesthetic.

Use image overlays where necessary to match the dark website theme.

---

# ANIMATIONS

Use tasteful modern animations, including:

* Fade-up on scroll
* Image scale on hover
* Card lift on hover
* Smooth button transitions
* Animated statistics
* Subtle text reveal animations

Do NOT make animations excessive or distracting.
